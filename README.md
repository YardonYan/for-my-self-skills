# for-my-self-skills

YardonYan 的可公开技能集，7 个。

## 怎么用

```
git clone https://github.com/YardonYan/for-my-self-skills.git
```

每个子目录是一套技能，先读里面的 `SKILL.md`，再按它引用的 `references/` 取细节。

## 包含哪些

| 技能 | 做什么 |
|---|---|
| html-skill-effectiveness | 单文件 HTML 工件：报告、看板、可视化页 |
| markdown-renderer-fix | Markdown 渲染、SSE 中文乱码、代码高亮、Mermaid、KaTeX |
| mobile-design-spec | iOS、Android、HarmonyOS、小程序、H5 五套尺寸规范 |
| task-skill-orchestrator | 复杂任务拆成 DAG，分波次并行 |
| tech-blog-generator | 从代码或文档生成技术博客，中英双语 |
| yardon-writer | 带个人风格的长文写作，双模式 |
| html-designer__skillhub | 网页视觉设计 |

## 不含哪些

5 个涉及个人信息的技能和技能路由只在私有层保存，不在这里公开。公开集不含个人上下文。
