# prompt-optimizer — 提示词优化器

> 一份草稿级 prompt 进去，四种策略的成品出来，你对比挑一个。

## 解决什么

「AI 没理解我的意思」这件事，九成不是模型不行，是 prompt 里缺了它需要的东西：目标受众、输出格式、边界条件、什么叫作完成了。

这个 Skill 不做那种「帮你润色一下」的温和改写。它按四种不同思路各重写一版，让你看到同一个需求在不同组织方式下的效果差异：

| 策略 | 核心思路 | 适合场景 |
|---|---|---|
| A 详细展开式 | 补上下文、约束、边界、输出格式、成功标准 | 任务清晰但缺细节，需要确定性输出 |
| B 角色扮演式 | 专家人设 + 思维链引导 | 深度分析、创意生成、策略建议 |
| C 结构化式 | 拆成 3~7 个子步骤，每步有输入输出与验证标准 | 复杂多步骤，AI 容易跳步 |
| D 逆向提炼式 | 从模糊需求推断真实目标，目标前置 | 自己也不太清楚要什么，探索性任务 |

## 什么时候用

```
帮我优化这个 prompt，给我几个版本对比。
这个提示词怎么写更好？
AI 没理解我的意思，帮我把这个需求写清楚。
```

即使你不说「prompt」这个词，只要表达的是「让指令更清晰、更有效」，它就该触发。

## 工作流

1. **理解意图** — 先一句话复述它对需求的理解，避免自作主张
2. **追问关键信息** — 缺得厉害时先问 1~2 个关键问题，别硬猜
3. **生成四种优化** — 按四种策略各出一版
4. **对比输出** — 统一格式呈现，末尾附策略对比表，方便直接选

## 输出形态

```
## 理解
[一句话复述]

## 优化结果
### A — 详细展开式
[可直接复制的完整 prompt]
### B / C / D …

## 快速对比
| 策略 | 特点 | 适合场景 |
```

每一版都是独立可用的成品，复制就能跑，不需要额外解释。

## 原则

- 不改变用户原意——优化是让表达更清晰，不是加新需求
- 语言跟随输入，中文进中文出
- 原 prompt 已经够好就不硬包装

## 安装

```bash
git clone https://github.com/YardonYan/for-my-self-skills.git
cp -r for-my-self-skills/prompt-optimizer <your-agent-skills-dir>/
```
