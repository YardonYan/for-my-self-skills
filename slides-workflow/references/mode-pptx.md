# 模式三：可编辑 PPTX

直接产出能在 PowerPoint 里改的 pptx。难度最高，但只有这一条路能交付给需要继续编辑的人。

## 什么时候选它

- 后续还要反复改内容、更新数据
- 要交给同事或客户继续编辑
- 有必须遵循的企业模板
- 图表要能改数

## 先做三页样稿

不要一次生成整套。先要三页：封面、内容最多的一页、图表或流程最复杂的一页。三页就能看出字体、间距、可编辑性到不到位，一次错三页比一次错三十页便宜得多。

## 制作提示词

```
请使用 [ppt-master 类 Skill]，根据已经确认的素材、逐页稿、风格说明，制作可编辑 PPTX。

先做三页样稿：
封面、内容最多的一页、图表或流程最复杂的一页。
如果页面类型有重合，请另选一页，覆盖不同的排版需求。
先保留原页码，方便与内容定稿核对。

可编辑要求：
1. 标题、正文、页码和关键数字使用可编辑文本框
2. 需要更新数据的图表，使用带可编辑数据的原生图表，不要用矩形、线条拼出外观后，视为已经满足要求
3. 表格使用可编辑表格，保留增删行列和修改内容的能力
4. 流程图的节点、文字和连接线分别可编辑；移动节点时，连接线应能跟随调整
5. 复杂插画和照片可以使用图片，但标题、正文和需要修改的标注应独立保留
6. 如提供了强制使用的 PPT 模板，请沿用原模板的母版、版式及公共元素

严格使用已经确认的内容，不新增观点、事实或数字。不要用整页图片代替可编辑页面。如果某项要求无法实现，请明确说明限制和替代方案，不要自行降低要求。
导出三页样稿的 PPTX 和对应预览图，说明哪些元素可编辑、哪些仍是图片，以及有无字体替换或其他需要注意的问题。
等我确认后，再继续制作全套。
```

样稿通过后再整套生成，提示词把「先做三页」换成「完成全部页面」，其余不变。

## 可编辑性的实际标准

「看起来能编辑」和「真的能编辑」是两件事。逐项验：

| 元素 | 合格 | 不合格 |
|---|---|---|
| 标题正文 | 点进去能改字，字号字体可调 | 整页是一张图，或文字是形状里的曲线 |
| 图表 | 右键编辑数据，能改数值 | 用矩形和线条拼出来的"图表" |
| 表格 | 能插入删除行列 | 一堆独立文本框摆成表格样子 |
| 流程图 | 节点、文字、连线分别选中；拖动节点连线跟随 | 整张图不可拆 |
| 数字 | 关键数字在文本框里，能改 | 数字在图里，要改就得重做图 |
| 母版 | 沿用提供的模板母版与版式 | 另起一套配色和版式 |

第 2 项最常被糊弄过去。形状拼出来的图表导出后和真图表一模一样，但改一个数值要重画整块。

## 模型差异很实在

同一份提示词，能力弱的模型出来的字距、间距、对齐都粗糙，要调很多轮；好模型出的一版就接近可用。这部分差距不是提示词能补的。

实践建议：正式场合用当前能拿到的最强模型；非正式场景够用就行，把省下的时间放在内容上。

## 从图片稿还原

已经有整页图片稿，后续又要改，才做这一步。核心是混合还原，而不是整页转图。

```
请使用 [ppt-master 类 Skill]，将我上传的整份 PDF 转换为 16:9 宽屏比例的可编辑 PPTX。
先按当前 Skill 说明选择适合的 PDF 转换或图片重建流程。

一、整套转换
处理 PDF 中的全部页面，保持原页序、页数和内容对应关系，不要漏页、重复页或擅自合并、拆分页面。
先检查 PDF 是文字型、图片型还是混合型，据此选择提取与重建方式。如原页面不是 16:9，不要拉伸或裁切内容，请说明适配方案。

二、还原目标
尽量保留原 PDF 的整体设计、构图、配色和图文位置，同时让主要文字可以在 PPT 中编辑。

采用混合还原方式：
- 标题、副标题、正文、标签、关键数字和页码，使用可编辑文本框
- 简单色块、线条和基础图形，尽量使用 PPT 原生形状
- 复杂照片、插画和纹理，保留为独立高清图片
- 需要更新数据的图表，使用我提供的原始数据重建；没有原始数据时，不猜测数值，明确说明编辑限制

优先使用上传的正式素材，避免从 PDF 中反复裁切、压缩图片；保持图片原比例和关键内容完整。

三、文字与背景处理
对照已确认的逐页稿核对文字和数字；如未提供逐页稿，以 PDF 为准，识别不清的内容列出待核对。
文字转为文本框后，必须清除背景中对应的原文字，避免出现重影，或修改后露出旧文字。不要将整页截图铺底，再覆盖文本框充当可编辑页面。
文字与复杂背景粘连时，优先使用原始素材或无字背景。确实无法干净拆分的区域，保留必要的图片形式，并在交付说明中标明，不要强行补画造成失真。
不得擅自改写内容，或改变产品外观、人物、Logo、图表含义及数据关系。

四、整套一致性与检查
统一同级标题、正文和页脚的字体、字号及位置规范，同时保留原 PDF 中不同页面的布局特点。不因统一格式而改变重点、遮挡内容或缩小文字硬塞。

逐页检查：
1. 文字有无错漏、重叠和溢出
2. 图片有无变形、模糊或裁切
3. 背景有无残留旧文字
4. 页序、数据、单位和来源是否准确

五、交付
直接完成整份 PDF 的转换，无需逐页等待确认。
如需分批处理，请自行管理页序，最后合并为一个 PPTX。
交付完整 PPTX 及对应的整套 PDF 预览，并按页码列出：仍保留为图片的主要内容、无法准确识别的文字、明显还原差异和需要人工核对的事项。
无法满足的要求如实说明，不将图片元素标为可编辑。
```

还原完打开 PPT 翻一遍，重点看两处：文字有没有重影（旧字没清干净），组件有没有错位（原本对齐的元素散开）。

拆不干净的区域，两条路：换回原始素材重做这一块，或者接受它保留为图片并在说明里写清。不要让它看起来像可编辑但其实是图。

## 混用

封面和视觉重点页用生图，内容页与数据页直接做可编辑 PPTX。按每页用途选，最后统一风格。效果最好，但操作最麻烦——两套工具、两套素材、一次对齐。页数多时不建议。

## 验收清单

- [ ] 三页样稿先确认，再出整套
- [ ] 标题正文页码数字都是真文本框
- [ ] 图表右键能编辑数据
- [ ] 表格能增删行列
- [ ] 流程图节点与连线可分别编辑
- [ ] 有模板时沿用原母版与版式
- [ ] 无整页图片冒充可编辑页
- [ ] 交付说明逐页标注哪些仍是图片、哪些需要人工核对
- [ ] 打开后无字体缺失、无组件错乱、无文字乱码
