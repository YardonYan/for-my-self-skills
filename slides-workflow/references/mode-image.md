# 模式二：整页图片

一页一张完整图片，文字、配图、背景都在图里。所见即所得，但改起来只能改图。

## 什么时候选它

- 想先看到最终画面，再决定要不要继续投入
- 只需要发送阅读或现场放，不需要别人编辑
- 视觉要求高，要做出设计感强的画面
- 内容已经定稿，不会再改

不适合：后续要反复改、要交给同事继续编辑、要更新数据图表。这三种情况直接走 `mode-pptx.md`。

## 制作提示词

```
请根据我上传的原始资料、正式素材、已确认的逐页稿和风格参考，生成一套 16:9 宽屏比例的幻灯片图片，用于 [汇报场合]，面向 [目标受众]。

使用 [生图模型] 生成图片。如果当前入口无法选择或确认该模型，请如实说明，不要仅凭提示词声称已切换模型。

一、内容依据
以已确认的逐页稿为内容依据，原始资料用于核对事实，正式素材用于页面展示，参考图片只用于借鉴视觉风格。
准确保留核心观点、数据、单位、时间和来源。允许为适应屏幕阅读精简措辞，但不能改变原意，不能自行补充事实、案例、数字或结论。发现资料冲突或关键信息缺失时，先指出，不要猜测。

二、视觉风格
提炼参考图中的配色、字体气质、标题层级、留白、对齐方式和图片处理方式，并贯穿整套页面。
根据每页内容选择合适的构图：封面突出主题，观点页突出结论，数据页突出比较，流程页突出步骤与关系。保持整体统一，同时让不同页面有各自的信息重点，不要每页套用同一个版式，也不要只换背景颜色。

三、信息表达
每页围绕一个明确主题组织信息，建立清楚的阅读顺序。避免大段文字堆砌，将补充说明留在逐页稿中，画面优先呈现观众需要看清、记住的内容。
根据内容需要使用图片、图表、流程图或机制示意图，不要为了装饰强行增加图形：
1. 数据比较：选择适合的图表，保留数值、单位和统计口径
2. 步骤说明：展示先后顺序、关键节点和必要分支
3. 机制解释：明确组成部分及其关系，不编造因果
4. 重点总结：提炼已有结论，不新增空泛口号

四、正式素材
按逐页稿使用指定图片，保持原比例和关键内容完整。
产品截图、人物、Logo 及原始图表不得擅自改画或替换。
如当前工具无法准确使用某项素材，请说明，不要生成一张看似相近的图片冒充原素材。

五、画面质量
每张图片对应一页完整幻灯片，画幅为 16:9，不生成电脑屏幕、投影幕布、透视样机或多页拼图。
文字直接呈现在图片中，使用清晰、足够大的中文，保证会议投屏时能够阅读。标题、正文、数据标签与页脚层级分明，四周保留安全边距，不出现文字截断、重叠或溢出。
不添加无关文案、随机英文、装饰性数字或额外水印。
不要用复杂纹理干扰正文，也不要以缩小字体的方式硬塞内容。

六、整套生成与交付
按照已确认的逐页稿，一次性完成全部页面，无需先生成样页或中途等待确认。
整套沿用统一的配色、字体气质、标题层级和页脚规范，根据各页内容调整构图，避免风格漂移或版式重复。
每页单独输出一张 16:9 高清图片，按"01_封面、02_页面标题……"依次命名，不要拼成多页长图或缩略图合集。
生成过程中逐页核对文字、数字、素材及页序，确保没有漏页、重复页或未经确认新增的内容。
全部完成后，按顺序交付所有图片；如当前环境支持文件打包，同时提供 ZIP 压缩包。

整套图片生成后，先核对文字、数字和素材，再检查排版，以及前后页面的风格是否一致。尤其留意中文错字、数据单位、图片细节，还有同一级标题是否忽大忽小。
```

## 文件名规范

```
01_封面.png
02_开场问题.png
03_市场现状.png
...
```

两位数字前缀保证排序正确，十页以上用两位仍然够。`verify.py assets` 会检查连续性与逐页稿引用是否对得上。

## 生成后必须做四轮核对

图片模型最容易在细节上出错，而且错得很自然，不盯着看不出来：

1. **文字**：中文错别字，尤其形近字；标题是否被截断在画面外
2. **数字**：单位、小数点、百分号；和原始资料逐条对
3. **素材**：产品截图有没有被改画，Logo 有没有变形，人脸有没有畸变
4. **一致性**：同一级标题在不同页是否一样大，页脚位置是否一致

发现局部问题就单独改那一页，改完重新检查整页——图片是对像素做修改，一改周边就可能跟着变。

## 合成 PDF

按页序合并，一页图对应一页 PDF：

```bash
# 用 ImageMagick（如果已装）
magick 01_封面.png 02_*.png ... out.pdf
```

或用任何能把图片按序合并成 PDF 的工具。合成后打开翻一遍，确认页序没错、没有漏页。

## 要不要还原成 PPTX

到这里就能交付了，前提是「只讲不改」。只要后续还要改内容、更数据、换图，就该走可编辑路线，见 `mode-pptx.md` 的「从图片稿还原」。

先想清楚这一点，比事后返工省事：图片里的文字已经和画面融合，还原要重新识别、拆分、排版，未必能同时做到完全一致和全部可编辑。

## 验收清单

- [ ] 每页一张 16:9 图片，不是拼图也不是样机图
- [ ] 按 `01_` 两位序号命名，页序与逐页稿一致
- [ ] 中文无错字，标题未被截断
- [ ] 数字、单位与原始资料逐条核对过
- [ ] 产品截图、Logo、人物未被改画
- [ ] 同级标题字号一致，页脚位置一致
- [ ] PDF 已合成，翻过一遍确认无漏页
