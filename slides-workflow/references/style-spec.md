# 阶段二：风格说明

风格说明是把「我喜欢这种感觉」翻译成可执行的参数。有了它，后面改某一页时有统一依据，不会改着改着像几套 PPT 拼在一起。

## 为什么用参考图而不是文字

「米白底色、大标题、留白多一点」这种描述，十个人能做出十个样子。一张图能让 AI 直接看到字号对比、边距比例和构图关系，比任何形容词都准。

参考图来源：

| 站点 | 特点 | 适合 |
|---|---|---|
| Pinterest | 量大，搜关键词命中率高 | 找整体气质 |
| SlidesCarnival | 免费模板站，成页可参考 | 找页面结构 |
| Slideland | 模板偏商务 | 找正式场合的构图 |
| prezman | 演示稿案例 | 找叙事节奏 |
| Awesome DESIGN.md | 网站设计语言分析库 | 找配色与字体组合 |

自己的旧稿、设计稿、别人的成品页同样可以当参考，往往比模板站更贴业务。

## 拆解提示词

```
请结合已经确认的逐页稿，分析我提供的风格参考。
本轮先确定设计方向，不生成 PPT、不生图。

我喜欢：[具体特点，例如米白底色、大标题、图片排布]
我不喜欢：[具体特点，例如装饰过多、正文太小]
使用场景：[现场投屏 / 电脑阅读 / 打印]
其他限制：[品牌色、中文字体、页面比例等；没有可留空]

先简要拆解参考图中的：配色、字体特征、字号层级、对齐方式、留白、图片处理和装饰元素。
请区分哪些是图片中能明确观察到的，哪些是你根据我的内容提出的设计建议。无法确认的字体，不要猜成确定的字体名称，可以推荐气质接近、支持中文的替代字体。
然后提出几个构图明显不同的设计方向，不要只是更换颜色。

每个方向说明：
1. 整体视觉特点，以及为什么适合这份内容
2. 背景色、正文色、强调色，给出建议色值
3. 中文字体、标题和正文字号、页面边距
4. 封面、普通图文页、数据页、流程页的布局建议；只覆盖逐页稿中实际需要的页面类型

保持整体风格一致，但不要让每页长得一模一样。参考图中的小字、低对比度或过密排版，如果不适合我的使用场景，请指出并调整。不要为了套用参考风格，擅自删改已经确认的核心内容。

等我选定方向后，再整理成"风格说明.md"。如果当前环境不能保存文件，就输出可直接复制的 Markdown。
后续制作沿用这份说明。
```

## 三个必须卡住的点

**区分观测与建议。** 参考图里能明确看到的（配色值、对齐方式、图片处理）和建议（你这份内容该用什么字号）要分开写。混在一起，后面就分不清哪些是参考图的约束、哪些是 AI 的发挥。

**字体不许猜。** 从截图里认不出字体是常态。要求 AI 写「气质接近、支持中文、可商用」的替代方案，不要写一个看起来很确定的字体名。中文场景还要确认目标机器上有没有这个字体。

**方向要多不要多色。** 只换配色不算新方向。真正不同的方向体现在构图：单栏还是分栏、图占满还是图文对分、信息密度高还是低。

## 场景适配检查

参考图好看但不一定适合你的使用场景，这一关必须过：

| 场景 | 要求 | 参考图常见问题 |
|---|---|---|
| 现场投屏 | 正文不小于 20pt，对比度要够 | 小字、浅灰字在投影仪上糊成一片 |
| 电脑阅读 | 正文 14-16pt 可接受，可以密一些 | 图好看但信息量不足 |
| 打印 | 避免大面积深色底，注意出血与页边距 | 深底打印耗墨且发灰 |

如果参考图的小字、低对比、过密排版不适合当前场景，要明确说出来并给替代方案，不要为了像参考图而牺牲可读性。

## 风格说明模板

产出的 `style-spec.md` 至少包含：

```markdown
# 风格说明

## 使用场景
现场投屏 / 电脑阅读 / 打印（决定字号与对比度下限）

## 色彩
- 背景：
- 正文：
- 强调：
- 辅助（用于图表与标签）：
- 色值格式统一，注明 HEX 或 RGB

## 字体
- 中文标题：字体名（备选）+ 字号 + 字重
- 中文正文：字体名（备选）+ 字号 + 行高
- 数字与英文：字体名 + 用法说明
- 无法确认原字体时，写明替代理由

## 版式
- 页面比例：16:9
- 页边距：上下 / 左右
- 栅格：几栏，间距多少

## 页面类型
| 类型 | 构图 | 要点 |
|---|---|---|
| 封面 | | |
| 普通图文页 | | |
| 数据页 | | |
| 流程页 | | |
只保留逐页稿里实际出现的类型

## 统一元素
- 页脚：内容与位置
- 页码：位置与样式
- 章节标识：是否需要

## 禁止项
- 明确不用的处理方式（例如：不要投影卡片、不要渐变背景）
```

## 跳过这一步的代价

可以只给参考图不做拆解，效果通常会差一点。不拆解的风险是：AI 每页各自理解一次风格，做到第七页时前面几页已经不像同一套了。真要跳，至少在提示词里加一句「整套沿用同一份视觉规则，不要每页重新决定风格」。
