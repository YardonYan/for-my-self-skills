# 阶段四：局部打磨

AI 交的第一版大概率不达标。这一阶段决定最终能不能用，也最容易把进度毁掉——多数翻车不是改不好，是改着改着一整套风格散了。

## 五段式修改指令

每次只改一处，指令写到 AI 不用猜的程度：

```
只修改第 [N] 页，以我提供的实际打开截图为依据。

问题：[实际看到的问题]
希望改成：[具体结果]
允许修改：[布局、字号、图片大小等范围]
需要保留：[满意的设计、原文、数值、其他页面]

请先判断原因，再调整相关对象。不要为了修复局部问题，重做整页或整套风格。
修改后重新导出并检查，确认原问题是否解决，同时检查有无新增的遮挡、溢出、变形或内容遗漏。
把修正保存到制作源文件，避免下次导出又恢复旧问题。交付修改后的文件，并简要说明改了什么。
```

五段缺一段就会出问题：

| 段落 | 不写的后果 |
|---|---|
| 只修改第 N 页 | AI 顺手把别页也"优化"了 |
| 问题（附截图） | AI 猜错位置，改了三处都不是你要的 |
| 希望改成 | 改完还是不对，因为标准只在你想里 |
| 允许修改 | AI 要么不敢动，要么动过头 |
| 需要保留 | 满意的地方被一起改掉 |

## 附截图这一条

文字描述位置不准。「右上角那个标题」到底是页面标题还是卡片标题，AI 只能猜。截一张图圈出来，命中率立刻不一样。

截图用实际打开的成品截，不要用导出前的设计稿——两者经常有出入。

## 两条纪律

**先判断原因，不要重做。**「这页不好看」不是问题描述。是字太多、是层级不清、是图和字打架，原因不同改法完全不同。让 AI 先说原因，再动手。

**同一问题两轮没改善就停下。** 继续重复生成只会更远，而且会把原本对的部分改坏。停下来做的事：确认截图是否准确、确认指令是否矛盾、换个模型试、或者自己上手改这一处。

## 不同形态的改动边界

| 形态 | 谁来改 | 注意 |
|---|---|---|
| 可编辑 PPTX | 自己能改就自己改 | 小移位、改字、调字号，人工比描述更快 |
| HTML Slides | 可让 AI 改，但要限定范围 | 改 CSS 容易连带影响其他页，要求改完检查全站 |
| 整页图片 | 只能改图，边界最难控 | 改完必须整页重检，局部改可能带歪周边 |

## 交付前检查清单

**内容**

- [ ] 无错别字，尤其形近字与专有名词
- [ ] 无漏页、无重复页
- [ ] 数字与原始资料逐条对过
- [ ] 单位、口径、时间范围齐全
- [ ] 来源标注准确

**画面**

- [ ] 文字没有被遮挡、截断、溢出
- [ ] 图片没有变形、拉伸、模糊
- [ ] 重点能一眼看到，不需要找
- [ ] 同级标题字号一致
- [ ] 页脚、页码位置一致

**操作**

- [ ] 翻页、动画、交互正常
- [ ] 断网后素材完整显示
- [ ] 全屏与窗口缩放下布局正常

**备用稿**

- [ ] PDF 与最终版本内容一致
- [ ] 动态页面在 PDF 里保留了完整关键信息
- [ ] PDF 无空白页、无隐藏内容、无演示按钮

## 什么时候该停手

以下情况继续改不如重做：

- 整套风格已经散了，改局部补不回来 → 回到阶段二重新定方向
- 内容本身有问题，改版式只是掩盖 → 回到阶段一重写逐页稿
- 需要频繁改又要视觉冲击 → 换形态（图片稿换可编辑，或反之）

判断标准很简单：连续三轮都在同一个地方打转，那就不是打磨问题，是上游决策错了。
