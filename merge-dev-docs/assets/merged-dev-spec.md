## 正文之外的三条约束

1. **不写代码能表达的东西**：字段清单、类图、函数签名一律改成指向源码路径。
2. **不写没有出处的规则**：合并稿里出现无 `[..]` 标记的新增条目，说明合并过程中擅自补了内容，要么删掉要么单列为「已知盲区」。
3. **不把两套文档并成两部分目录**：章节必须按主题重排，同一主题只出现一次。
