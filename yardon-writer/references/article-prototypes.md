# 文章原型

> 写之前先定原型，每种原型的重心完全不同，混着写会散。

## 1. 技术教程型（A 模式）

**适用**：框架入门、原理拆解、实战系列、API 用法。
**重心**：概念讲透 → 代码能跑 → 坑点提醒。
**他的素材**：五个已写的系列（React、FastAPI、LangChain-RAG、Docker/K8s、Vue3），加上 DocRAG、AgentHub 里的真实实现。
**注意**：

- 别写成 API 文档翻译。每节都要有「为什么需要它」。
- 类比是这类文章的命，一个抽象概念配一个日常场景。
- 结尾必须留一处「我第一次写的时候也踩了」的真实经验。

## 2. 落地复盘型（B 模式，他的独占优势）

**适用**：一个真实项目从需求到上线的完整过程，尤其是「业务说不清、平台有硬限制」的局面。
**重心**：先讲约束有多难 → 再讲怎么绕 → 最后讲代价和收获。
**他的素材**：企业侧 Agent 落地、双平台部署、平台限制突破、三人小组统筹。
**注意**：

- 这类文章的稀缺性极高。市面上讲怎么用 AI 写代码的人一堆，讲怎么在公司里把 Agent 真跑起来的人很少。
- 脱敏是硬要求。不写公司名、客户名、内部数据、服务器地址。抽象成「某类低代码平台」而不是具体产品。
- 重点不是「我做成了」，是「我在什么约束下做了取舍」。取舍才是判断力，判断力才是别人抄不走的。

## 3. 踩坑实录型（B 模式）

**适用**：一个具体的坑，从踩进去到爬出来的全过程。
**重心**：现象复现 → 错误猜测 → 真正原因 → 通用解法。
**他的素材**：去重哈希漏字段导致丢数据、配置不持久化、N:1 绑定限制、零测试覆盖率、无鉴权的隐患。
**注意**：

- 一定要写「我先猜的是 X，结果不是」，这个过程比结论值钱。
- 结尾提炼成一句可复用的通则，让读者能套到自己的场景里。
- 别把坑写成炫耀。写清楚当时有多狼狈。

## 4. 观点解读型（B 模式）

**适用**：一个行业现象、一条新闻、一个工具发布，你要说点不一样的。
**重心**：观察 → 好奇 → 研究 → 给出自己的判断。
**他的素材**：一线落地看到的东西，这是他的信息差。行业里的人怎么想、业务方真正卡在哪、AI 在真实流程里哪些环节根本用不上。
**注意**：

- 先承认对方处境的合理性，再切自己的角度。别一上来就反驳。
- 判断要敢下，但给出依据。「我认为」后面必须跟「因为我在真实项目里看到」。
- 不要为了凑热点写。选题过 HKR 质检，占不到两项就放弃。

## 5. 方法论分享型（B 模式）

**适用**：把长期积累的经验系统性掏出来。
**重心**：每一节都要有可执行的动作 → 坦诚说学习成本和失败点 → 结尾回扣。
**他的素材**：先标准化再动代码（字段清单 / Schema / 校验规则）、脱敏三原则、问题模式库、分步迭代 P0 到 P2、给管理层多版方案供选。
**注意**：

- 开头必须有谦逊铺垫，卸掉「我来教你」的傲慢。写「我自己的做法未必通用」，不写「正确的方法论是」。
- 必须写失败点和学习曲线。只画饼的方法论没有价值。
- 每节结尾给读者一个今天就能做的动作。
- 结尾把所有动作点回扣一遍，再升一级。

## 6. 短图文对比型（A 模式变体）

**适用**：5 个以上产品/工具的横向对比，读者要在第一屏看出差异。
**重心**：一张定位图 + 模型/Skill/共通能力三张表 + 场景矩阵 + 选型流程；正文只保留判断，不写长篇产品介绍。

**硬约束**：

- 总字数 5–7 千字，表格 5–8 张，图 1–2 张。
- 深挖版加 8 层护城河矩阵（工作面/上下文/分发/扩展/成本/信任/切换成本/资本品牌）+ 证据表 + 因果链表 + 竞争格局 + 护城河衰减表；总字数 8–9 千字，表格 9–11 张。
- 开头一句话说清每个产品交付什么，不从本地环境切入。
- 每个产品补公司、上线、最新、用户/规模、入门价、模型。
- 文中不放脚注/引用；数据口径统一放在结尾一句。
- 先分组再对比：按模型路线、按 Skill 扩展路线、共通能力。
- 每个产品都要有一行“最新版本 + 这一版新增 + 独有组合 + 代价”；不能只深挖一个产品。
- 星级必须带评分标准和两个真实任务产出，不能只给分数。

**注意**：

- 不要把五个产品写成五篇小论文；每节控制在 3–5 行。
- 场景矩阵用星级/强弱，不用大段形容词。
- 结论要敢下：办公选谁、编程选谁、跨应用选谁。

## 选原型速查

| 你手里的东西 | 选哪个 |
|---|---|
| 一个新框架 / 一个新概念 | 1 技术教程型 |
| 一个自己做完的项目 | 2 落地复盘型 |
| 一个把自己坑惨的问题 | 3 踩坑实录型 |
| 一条让你有想法的行业消息 | 4 观点解读型 |
| 一套用了很久的工作方法 | 5 方法论分享型 |
| 5 个以上产品横向对比 | 6 短图文对比型 |
