# 禁用清单与四层自检

## 一、禁用词表（两边合并，命中即改）

### 套话开头与转折

- 首先……其次……最后
- 综上所述、总而言之、总的来说
- 值得注意的是、值得一提的是、不得不说
- 不难发现、众所周知
- 让我们来看看、接下来让我们
- 随着……的发展、在当今……的时代

### AI 高频踩雷词

- 说白了
- 意味着什么？
- 本质上、换句话说、换句话说来说
- 赋能、抓手、闭环、生态、助力、加持
- 全方位、多维度、深层次
- 在 AI 快速发展的今天

### 他自己的雷区

- 绕圈句式：「进行了一个……的一个」「对于……这方面的话」
- 绝对化表述：「一定能」「绝对」「必然会」（改成「大概率」「在我这个场景下」）
- 编造数字：没有出处的具体数字一律不写

## 二、分场景标点规则

| 符号 | A 模式技术文 | B 模式叙事文 |
|---|---|---|
| 冒号 | 可用，用于术语定义和代码说明 | 禁用，改逗号或句号断开 |
| 破折号 | 收敛，能改就改 | 禁用，改逗号或断句 |
| 双引号 | 代码内保留，正文改「」 | 统一用「」 |
| 分号 | 可用 | 少用，改句号 |
| 省略号 | 可用 | 可用，表达语气拖长 |
| 感叹号 | 少用 | 可用，一处即可，多了像促销文案 |

## 三、四层自检

### L1 结构层

A 模式：

- [ ] 每节都有「为什么需要它」，不只是「它是什么」
- [ ] 代码能跑，不是伪代码
- [ ] 概念对照有表格，且只对比有差异的维度
- [ ] 本章小结和下一章预告都在

B 模式：

- [ ] 开头是一个具体场景，不是宏大叙事
- [ ] 有一条清晰的主线，偏离处都有扣主线句
- [ ] 结尾回环了开头的钩子
- [ ] 没有为了凑字数硬加的段落

### L2 节奏层

- [ ] 连续三句长度相近的地方，已经打断
- [ ] 全文至少三处一句话独立成段
- [ ] 至少有一句短判断句钉住重点
- [ ] 有口语转场，不是靠小标题硬切
- [ ] 疑问句或自问自答至少出现一处

### L3 真实感层

- [ ] 第一人称真实经历至少一处，且不是编的
- [ ] 至少写了一个失败、弯路或不确定的地方
- [ ] 情绪是体感描写，不是形容词堆叠
- [ ] 没有编造的数据、金额、对话
- [ ] 涉及公司业务的地方已经脱敏

### L4 Yardon 味层（最关键）

- [ ] 至少有一个生活化类比，且落到了具体场景
- [ ] 至少有一处「我建议」「我踩过」这类带判断的话
- [ ] 术语第一次出现有解释
- [ ] 读起来像他本人在讲，不像一篇标准技术稿
- [ ] 通篇没有命中禁用词表

### 通过标准

L1 全通过，L2 至少四项，L3 全通过，L4 全通过。
L3 或 L4 有任何一项不过，必须返工，不能将就。这两层决定文章是不是活人写的。
