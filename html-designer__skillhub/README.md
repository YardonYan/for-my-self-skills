> 不是套模板，而是按排版、配色、层级、栅格和可访问性，把设计意图写成干净的 HTML/CSS。

这是一个网页视觉设计 Skill，覆盖图形设计原则、字体系统、配色、视觉层级、栅格布局和可访问性。它附带 4 份设计参考和 5 个可直接打开的 HTML 示例，适合做落地页、作品集、营销页和设计系统。

> 说明：这是从 SkillHub 收集的第三方 Skill，不是 Yardon 原创。这里保留原始 `SKILL.md`、`references/` 和 `assets/`，方便直接加载；来源与版本见 `_skillhub_meta.json`。

## 解决什么问题

- 页面“能用但不好看”：字号、行距、留白、层级没有依据
- 配色靠感觉：主色、强调色、背景色互相打架
- 移动端和桌面端各自为政，栅格和断点不统一
- 视觉设计做完才发现对比度、焦点态、语义结构不合格

## 什么时候用

适合：

- 产品落地页、营销页、活动页
- 个人作品集、项目展示页
- 设计系统、组件规范、配色与字体方案
- 把一张设计稿或一段设计描述落成 HTML/CSS
- 给现有页面做视觉重设计

不适合：

- 后端逻辑、数据库、鉴权、支付
- 只想要一张位图海报（用图像生成工具更合适）
- 需要复杂前端框架状态管理的业务页面
