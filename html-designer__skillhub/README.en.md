> Not a template pack. It turns design intent into clean HTML/CSS using typography, color, hierarchy, grids and accessibility.

A web visual design skill covering graphic design principles, type systems, color, visual hierarchy, grid layout and accessibility. It ships with 4 design references and 5 openable HTML examples for landing pages, portfolios, marketing pages and design systems.

> Note: this is a third-party skill collected from SkillHub, not original work by Yardon. The original `SKILL.md`, `references/` and `assets/` are kept here so the skill can be loaded directly. Source and version are recorded in `_skillhub_meta.json`.

## What it solves

- Pages that work but look unpolished: arbitrary font sizes, line heights, spacing and hierarchy
- Color choices by feel: primary, accent and background colors fighting each other
- Mobile and desktop layouts that do not share the same grid or breakpoints
- Visual design that ignores contrast, focus states and semantic structure

## When to use

Good for:

- Product landing pages, campaign pages, event pages
- Personal portfolios and project showcases
- Design systems, component specs, type and color schemes
- Turning a mockup or a design brief into HTML/CSS
- Visual redesign of an existing page

Not for:

- Backend logic, databases, auth or payments
- Raster poster generation (use an image generation tool)
- Complex application state management in a frontend framework

## Install

Ask an Agent Skills-compatible tool to install it:


Or clone the repo and copy `html-designer__skillhub/` into your agent's skills directory. Make sure `SKILL.md` sits at the root of the skill folder.
